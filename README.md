# Вопросы для собеседования на позицию администратора Linux и DevOps инженера.

В данном репозитории представлены вопросы для собеседований по основным темам Linux инженера и/или DevOps инженера. У каждого вопроса есть ответ — он спрятан под спойлером «Ответ».

Список актуализирован в сентябре 2026 года: добавлены вопросы по современным инструментам и практикам (cgroups v2, eBPF, Gateway API, нативные sidecar, OpenTofu, OpenTelemetry, supply chain security и др.).
